安装与连接指引 Windows / macOS
  1. 在这里准备并运行安装器。点击下方“准备安装器”，完成后直接运行；也可以打开专用安装位置。无需管理员、API Key 或端口设置。支持 Windows / macOS 的 Chrome 和 Edge。
  2. 打开你要连接的 Grok Bot。点“生成配对话”，复制发送给它。连接器会短暂打开它的例程面板，自动完成配对。
  3. 回到 X，按设定次数连点大肥鱼开始研究。首次点击报告链接时，浏览器可能请你允许打开 Grok Bot。

连接组件安装与修复

安装器会放进专用目录，不用在原安装包里找文件。已有配对会保留。

浏览器或系统可能请你确认打开安装文件，请按提示操作。Windows 是单个 CMD 安装器；Mac 解压后是单个 COMMAND 安装器。请保留最初加载插件的完整文件夹。

正在检测本机连接组件…

在 1.5 秒内完成所选次数才会发送研究，次数不足只摸摸头；超时从下一次点击重新计数。信息流中达标后，5 秒内选择帖子；随时按 Esc 退出。

只发送你选择的帖子正文、作者和链接。网页内容会交给你的 Bot 及其使用的服务；连接资料由系统加密保护（Windows 用户加密 / Mac 钥匙串加密）。请保持 Grok Bot 登录、电脑和浏览器在线。研究使用你的 Grok Bot 用量。

连接方式、离线和断开说明

试用版使用自动建立的临时网络通道，无需配置服务器，但不能保证持续在线。连接中断时可到 Bot 查看已发出的任务。断开连接不会删除 Bot 中的报告或例程。

WELCOME ABOARD

把她带进你的浏览器。

加载一次，之后就可以在普通网页里见到她。

  1. 打开 Chrome 扩展程序页：chrome://extensions。
  2. 开启右上角的“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择项目里的 extension 文件夹。
  4. 打开或刷新普通网页，大肥鱼会出现在右下角。把扩展固定到工具栏，随时调整设置。

Chrome 设置页、扩展商店等受保护页面不支持宠物显示。升级后重新加载扩展，并刷新已打开的网页。

支持 Windows 与 macOS 的 Chrome / Edge。账户查询在“账户数据”中配置；AI 研究在“AI 连接与任务”中配对。地址自动监控与定时新闻尚未开放。
