## 安装与检查更新

- Windows 下载 Releases 中的 `dafeiyu-v版本号.zip`；Mac 下载 `dafeiyu-v版本号-macOS.zip`（M / Intel 共用）。源码页面的 Download ZIP 不含 AI 连接所需的运行组件，普通用户请下载 Releases 安装包。
- 初次安装：解压并保留文件夹，在 Chrome / Edge 扩展管理页开启开发者模式，加载其中的 `extension` 文件夹。
- 已安装用户：点击插件面板左下方或小屋右上角版本号旁的“检查更新”。发现新版后可直接下载对应系统的安装包、查看发布说明。
- **当前解压版需要将新版覆盖到原安装目录，再在扩展管理页重新加载、刷新网页。不要卸载重装，也不要另选一个新版目录加载，以免扩展 ID 改变、原设置不可用。** 仅下载不会自动安装。Chrome 对普通 Windows / macOS 自托管扩展的更新有限制，详见 [Chrome 官方分发说明](https://developer.chrome.com/docs/extensions/how-to/distribute)。
- 检查只读取 GitHub 的公开版本元数据，不上传钱包、API Key、Bot 对话或其他账户数据；成功结果缓存 5 分钟，重复点击合并。断网、限频、未发布版本会明确提示，并保留发布页入口。

## 开发

使用 Node.js 24，运行 `npm ci`、`npm run check`、`npm test`。浏览器用例需先运行 `npx playwright install chromium`，新版更新用例为 `npm run test:updates`。测试使用隔离配置和模拟响应。少数历史浏览器用例使用 Edge，可按脚本指定浏览器；更新用例支持 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定可执行文件。

`extension/` 为插件，`connector/` 为可选 AI 连接组件，`tests/` 为回归测试。Git 源码不包含本地账户配置、诊断记录、运行日志或第三方运行二进制。需要运行或打包 AI 组件时，从对应版本的正式包中取出 `connector/bin/`，其中包含 Node.js、cloudflared 及许可证；普通陪伴与账户查询不需要安装 AI 组件。发布流程见 [发布说明](docs/RELEASING.md)。

## Grok Bot：首次连接

1. 加载或重新加载本包 `extension` 文件夹，刷新已打开的网页。
2. 工具栏插件 → **AI 连接** → **准备安装器**。Windows 保存完成后点 **运行安装器**；如果浏览器没有直接打开，点 **打开安装位置**，专用目录里只有一个 CMD 文件。Mac 点 **打开安装包**，解压后双击唯一的 COMMAND 文件（自动识别 M 系列 / Intel）。浏览器或系统若要求确认，按提示处理；不自动跳过系统确认。
3. 完成安装后设置页自动检测组件，再点 **生成配对话**。组件内置运行环境，无需管理员、Node.js、API Key 或端口设置。请保留完整解压包及原先加载的 extension 目录，安装器会定位并调用其中的组件，无需手动找路径。Mac 需要 13.5 或更新版本。
4. 把生成的那一句话发给自己新建或选定的 Bot。保持小屋设置页和 Grok Bot 桌面版打开。Bot 会创建仅 webhook 触发的连接例程；组件通过 Grok Bot 官方面板完成连接。如果弹窗挡住面板，关闭弹窗并点“继续连接”。不需要手抄 webhook 密钥。
5. 配对成功后默认开启 X 项目研究。在帖子详情内，默认 1.5 秒内连点大肥鱼 3 次才发送；信息流里先完成连点，再在 5 秒内点要研究的帖子；未选择自动退出，随时可按 Esc 或关闭气泡取消。可在“AI 连接与任务 → 发送研究需要连点几次”或“陪伴设置 → 单击显示内容”选择 1–5 次，超时从下一次点击重新计数。识别外层帖子的正文、作者和链接，排除引用内容；兼容用户名大小写、X/Twitter 链接和 `/i/web/status` 地址。详情页正文尚在加载时最多等待 1.5 秒，离开或取消后不提交；只含图片且无文字的帖子暂不支持。
6. 完成后，所有允许显示大肥鱼的普通网页都会收到未读提醒；后台标签页在返回时显示。点击气泡打开对应 Bot，或关闭气泡，都会同步标为已读。首次跳转可能需允许浏览器打开 Grok Bot。小屋保留最近任务，包括失败、未确认和重启中断的任务。

安装包不含预设 Bot、旧测试链接、用户账户或密钥。每次配对都生成新的随机地址，20 分钟有效、单次使用；每个任务另有独立回传令牌。网页只接收状态与 Bot 跳转链接，不接收例程密钥。Windows 使用当前用户 DPAPI 加密，资料位于 `%LOCALAPPDATA%\TrenchWhale\GrokData`。Mac 使用钥匙串保存加密密钥，连接资料用 AES-256-GCM 加密后保存在 `~/Library/Application Support/TrenchWhale/GrokData`。配对前只读取 Grok Bot 当前账户标识、当前选中 Bot 和 Bot 名单这三个明确的客户端元数据项，核对当前 Bot 的真实 ID；不会读取账号登录凭据或剪贴板，不会按重名猜选其他 Bot。进入本次唯一例程后，再校验官方 Webhook URL 中的例程 ID，最后读取并加密保存连接信息。元数据不可用或账户／会话在读取期间改变时停止并提示重试。当前已核对 Grok Bot 0.78.1 的元数据格式，应用升级改变格式时需更新适配。连接组件在各自 TrenchWhale 目录下的 Connector；注册仅作用于当前系统用户的 Chrome / Edge。移动插件文件夹后请重新运行安装组件。

**试用范围与限制：**Grok Bot 配对最后一步依赖官方桌面面板的可访问性控件。Windows 已核对 0.78.1 中文界面；Mac 已提供系统事件适配器，需要实机确认对应界面，应用改版可能需要调整。Mac 首次按系统提示授予当前浏览器／连接组件辅助功能或自动化访问，以及钥匙串访问，再点“继续连接”。这些系统授权不能自动跳过。安装脚本尚未做 Apple Developer ID 签名与公证，首次打开可能需要按 macOS 的安全提示允许；不需要关闭系统安全检查，对外正式分发前仍需完成签名、公证和 Mac 实机验收。

组件使用 Cloudflare Quick Tunnel 临时通道，无需用户配置服务器，但没有长期在线保证；每次运行的地址自动生成，并先实际验证回传通道再给出配对话。沿用环境变量或系统手动 HTTP(S) 代理，Mac PAC 自动配置目前未验证。保持电脑、浏览器在线和 Grok Bot 登录。重启后配对仍保存，在途任务标记中断并引导去 Bot 查看，新任务建立新通道。一次最多 3 个处理中任务；发送未确认时不自动重发，防止重复用量。两小时未完成的任务可在 Bot 查看。

只在用户点击后发送所选帖子正文、作者、链接给用户配置的 Grok Bot，不上传其他标签页、Cookie、钱包密钥或全站信息流；公开服务只提供配对、结果回传和只读连通检测，均使用随机路径，不能执行任意本机命令。帖子内容按不可信资料处理，研究例程不授权交易或发帖。使用 Grok Bot 本身的用量与联网能力，报告准确性仍需自行核对。没有加入每小时定时热点或 Codex 连接。

完成通知先持久保存，再分发到所有未屏蔽的普通网页。完成气泡在页面上持续显示，不按 5 秒自动消失。点击报告链接或明确关闭后才标为已读，并同步关闭所有页面上的同一条提醒；其他未读项目仍保留。点击回执单独持久化，即使已读请求失败或发起网页关闭，后台仍可补写；后台页面回来后先核对最新状态再展示，已读消息不会再次出现。网页隐藏、口袋模式或不打扰名单仍然有效；Chrome 设置页等受保护页面无法显示。新打开的网页会读取未读通知；浏览器后台服务重启不会清空。记录保留 7 天、最多 100 条；升级会补入近期已完成任务，所以可能看到一次旧任务提醒。关闭网页陪伴不会取消交给 Bot 的任务。断开 Bot 会清除本机配对与记录，不删除 Bot 已有报告或例程；需要时可在 Grok Bot 里手动删掉 `大肥鱼连接·…` 例程。

## 币安只读账户

官方 API 入口：[API 管理](https://www.binance.com/zh-CN/my/settings/api-management)。网页路径为头像 → 账户 → API 管理；App 可切换 Pro 后从更多服务里的 API 管理进入。按[官方创建教程](https://www.binance.com/en/support/faq/detail/360002502072)创建系统生成的 API，获得 API Key 与 Secret Key，只开启读取权限，在小屋“账户数据 → 币安”中填写并“保存并检测币安”。不需要发到聊天中。

可选择五组最多两行的内容：

- 总资产估值＋现货与 USDT 合约今日估算（新安装默认）；合约资料不足时只显示“现货今日估算”。
- 总资产估值＋现货今日估算。
- 账户总资产估值（USDT）＋ USDT 合约持仓浮盈。
- 账户总资产估值（USDT）＋其中现货估值；第二项包含于第一项，不是相加关系。
- USDT 合约权益＋持仓浮盈。

升级用户可以在“币安气泡显示内容”选择第一项“总资产＋今日盈亏估算”；保留已经选择的其他显示模式。

今日统计从 UTC 0 点（北京时间 08:00）开始，币种统一为 USDT。现货估算 = 当前现货估值 - 昨日日终 BTC 估值折算值 - 当日净转入。抵扣可查充值、提现、12 类现货通用划转；非 USDT 资金移动按事件所在分钟行情估值，日终 BTC 估值有截断精度误差。未覆盖理财申赎、法币直接出入金、子账户等其他资金路径，因此这不是币安官方全账户今日盈亏，使用这些路径的账户结果可能不准确。

合约今日估算 = 当日已实现盈亏 + 资金费 + 手续费等已支持 USDT 收益项 + 当前浮盈 - 期初浮盈；划转不计盈利。仅包含 USDT 合约，不含 USDC、币本位及其他产品，遇到未知收益类型则回退到现货。成功返回空合约资产且当日收益记录为空时按用户指定口径显示 0；请求失败、字段缺失、流水分页不完整、未取得当日期初快照均不填 0。

日终快照读取权重较高，有效基准按账户和 UTC 日期缓存最多 15 分钟，缺少当日基准的响应最多缓存 1 分钟；账户/密钥变化会清除基准。大幅盈亏会额外核对一次基准，防止较早返回的不完整快照被全天沿用；这只是异常检测，不能保证上游重复返回的相同错误数据被识别。当前估值与流水每次点击刷新；服务器时间短期复用，已结束的历史分钟价格复用，无依赖的请求最多 3 个并行，并按请求预算与冷却状态限流。流水超过分页或请求预算会明确报告，不给出部分合计。算法及范围参考[币安现货 PnL 说明](https://www.binance.com/en/support/faq/detail/c681d247dde746b7833426fd6a7e09fc)、[日终快照接口](https://developers.binance.com/en/docs/catalog/core-trading-wallet/api/rest-api/account)。

资产估值使用 `GET /sapi/v1/asset/wallet/balance?quoteAsset=USDT` 的各钱包返回值相加；覆盖范围以此 API 返回的钱包为准，未返回的子账户不包含。合约部分使用 `GET /fapi/v3/account` 的 USDT 资产数据，只取 USDT，不把 USDC 或其他计价资产混加。**USDT 合约浮盈是当前未实现盈亏，不是全账户今日盈亏**。合约查询失败时可保留已取得的总资产，浮盈显示“未取得”；成功返回空资产列表显示 0；悬停气泡可看范围与失败原因。

每次正常单击重新查询，正在执行的相同请求合并；先显示最近 5 分钟内的已有结果，标明“上次时间 · 更新中”，再替换为本次结果。没有缓存时先显示已取得的资产，盈亏稍后补齐。API 自身更新延迟仍可能存在。气泡在查询结束 5 秒后关闭，不持续自动请求币安。遇到 429/418 停止请求并保存冷却时间。GMGN 使用更保守的点击刷新策略：查询结束后至少缓存 60 秒，期间只展示上次结果，不请求 API；60 秒后再次点击才刷新，若服务器要求更长冷却则继续等待。刷新失败保留同一 API、同一钱包范围的有效旧字段，行内标“上次”，悬停可查看对应字段时间；从未成功取得的数据不伪装成 0。

Key 与 Secret 保存在扩展专属 IndexedDB，不进入共享宠物设置，不回显。请求限于币安官方账户时间、钱包估值、合约账户、合约收益历史、日终快照、充值/提现/通用划转历史以及分钟行情的 GET 查询，HMAC-SHA256 在扩展后台签名。没有交易、划转、提币、登录 Cookie 抓取或通用请求代理。浏览器存储不等同于系统密钥库，不声称已额外加密。清除配置会取消正在进行的查询。

当前支持 Binance.com 的上述接口；区域独立站、统一保证金与具体账户权限仍需实际验证。**2026-10-28 已用用户保存的只读 API 实测钱包估值接口返回 HTTP 200，资产查询可用，并在隔离浏览器中通过快捷按钮切换、普通网页单击显示和再次单击重新请求的实测；已确认该账户合约资产及当日收益返回空，按用户指定规则显示 0；UTC 今日估算也通过真实 API 与连续单击刷新验证。具体账户产品覆盖仍需核对。签名、字段解析、限频、取消、凭据隔离与界面另有模拟测试覆盖。** 不应据此承诺与币安资产首页的所有产品完全一致。

接口参考：[钱包资产](https://developers.binance.com/en/docs/catalog/core-trading-wallet/api/rest-api/asset)、[USDT 合约账户](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/account)。

## 两行 GMGN 小账本

首次使用可在“账户数据 → GMGN”只填写并保存 API Key，地址留空；再打开已登录且钱包已加载的 GMGN 页面，单击大肥鱼尝试识别并查询。保存 API 本身不代表密钥已通过接口验证。自动识别依赖网页加载的名单，不能保证拿到全部链、全部钱包；设置页提供手动维护说明。若填写地址，选择网络后每行粘贴一个，切换网络分别填写，一次保存全部网络。每条链最多 20 个地址，重复地址自动合并；不支持或错误地址会阻止保存。已有 API Key 留空即可保留。

支持 BSC、Solana、Ethereum、Base、Arbitrum、HyperEVM、Robinhood、Arc、Stable。GMGN 网页跟随该标签页的当前链；其他网站使用设置中的默认网络，不会被另一个 GMGN 标签页改变。单击查询时最多每 1 小时读取一次 GMGN 网页自身的钱包名单，优先读取当前 GMGN 页，其他网页固定显示 GMGN 时读取已打开的 GMGN 标签页。成功识别后更新对应链的名单并重新统计；连点、多标签页及浏览器后台重启不会绕过检查间隔。没有定时扫描，也不刷新或切换用户网页。

同步只接受能核对单一账户归属的有效钱包列表，缺少的链保留原名单；明确返回空名单的链会清除该链旧地址。网页尚未加载、未登录或全部列表为空而无法核对归属时不猜测删除；保留原名单，说明显示在钱包设置页。检测期间手动保存的编辑优先，迟到的自动检测结果不能覆盖它。检测到不同账户时不会沿用已识别的上个账户钱包。

气泡最多两行：当前链原生币余额（BNB、SOL 等）和 API 的“1日已实现”盈亏。余额黑色，盈利绿色，亏损红色，零显示黑色。不把主币余额称为全链总资产，也不把 API 1d 已实现字段称为 GMGN 主页 24h 或今日总盈亏。

查询结束后至少缓存 60 秒，冷却期间点击只展示已保存结果，不发 API 请求；到期后下一次点击才刷新，没有定时反复查询。同一范围的并发查询合并，冷却跨标签页和后台服务重启保存。刷新时可先展示旧值和已返回的新盈亏，全部钱包余额取得后才替换余额合计；失败保留上次有效字段并明确标记及时间，不将部分钱包余额当总额。气泡约每 450 毫秒读取本机查询进度，不会因此增加网络请求；查询结束后显示 5 秒，隐藏后停止界面轮询。

2026-10-29 实际账户验证发现，原先按文档权重安排的 500ms 余额请求间隔仍会返回 429。因此改为保守串行查询，前一次完成后至少间隔 2.1 秒；首次查询会更久，之后通过 60 秒缓存提供即时显示。服务器 Retry-After / reset_at 要求更长时优先遵守，并对所有链统一冷却，不换 Key 或重复请求绕过。API 或钱包范围实际改变时旧请求和缓存失效；重复保存相同配置不绕过冷却。

币安与 GMGN 均采用短消息启动查询、按查询编号读取进度。网络响应与数据库访问设有截止时间，过期请求会释放；浏览器后台服务重启后，打开的气泡会尝试恢复一次，后续单击也能重新查询，不要求刷新网页。后台切回和页面缓存恢复时重新连接。失败的请求不会当作零资产；成功返回空资产才按 0 显示。升级插件后仍建议刷新已经打开的旧网页一次。

## 安装

Windows 双击 **预览小屋.cmd**，Mac 双击 **预览小屋-Mac.command** 看动作与界面，无需加载扩展。预览设置和真实插件设置分别保存。准备使用时运行对应的 **安装插件.cmd** 或 **安装插件-Mac.command**，打开扩展管理页和 extension 文件夹，再按下面步骤加载。

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启右上角“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本项目的 **extension** 文件夹。
4. 打开或刷新普通网页。固定扩展到工具栏，点击图标进入宠物小屋。

基础陪伴无需 npm、账号登录或 API Key；GMGN 连接检测需要用户自己填写 API Key。运行插件只需要 extension 文件夹。升级后请重新加载扩展并刷新旧网页。

## 使用提示

- 宠物仅显示在普通网页。Chrome 设置页、扩展商店等受保护页面不能注入。
- 单击音效默认开启，取自用户新视频中 8.105–8.445 秒的一声“叽”。音频为 0.34 秒、48 kHz、单声道，保持原速与原音色，调整音量并对首尾做短淡入淡出；没有循环或叠加第二声。可在“陪伴设置 → 单击音效”关闭；提醒提示音仍默认关闭。浏览器需用户点击后才允许播放声音。音效从本地资源读取，无外部请求。
- 按 Tab 聚焦宠物后，Enter / 空格摸头，方向键移动（Shift 加快），Shift+F10 打开菜单，Esc 关闭气泡或菜单。
- 位置和偏好会在同一浏览器的标签页间同步。数据保存在 chrome.storage.local，卸载插件会删除本地名单和设置。
- 图鉴与实际播放使用同一套 V0.1 原图。动画采用局部网格变形：原图形象锁定，仅调整动作幅度、速度和惯性。没有 WebGL 的环境会保留原图显示和音效，局部网格动画不可用。

`npm run test:soak` 默认运行约 20 分钟的隔离浏览器耐久测试；可用 `SOAK_MINUTES` 设置时长。测试通过模拟账户接口与 Bot 状态，在真实标签页中检查通知、冻结页面、后台服务终止以及长时间未访问页面的恢复。所有网络账户和 Bot 通道都在独立测试副本内替换，不会使用日常浏览器的配置或向真实 Bot 派任务。它验证浏览器与插件生命周期，不代表 GMGN/币安真实 API 或真实 AI 输出的在线稳定性。

浏览器测试使用 Edge 的独立测试配置，不读取或修改日常浏览器的用户数据。包含状态/物理测试、扩展兼容场景和动画/音效场景；动画检查包括真实鼠标拖动、截图像素差异，以及普通页面、严格 CSP 页面和本地预览实际启用网格动画的检查。浏览器验证音频成功解码、启动和静音；音色仍需要人工试听。

本次修复没有生成新角色素材。源图仅为 `extension/assets/whale-poses.png`。形象检查会与 V0.1 发布包核对 SHA256，并逐像素检查 12 个静止基准姿态和 11 个动画中的受保护脸部区域。读报的眼睛移动及拖动时的 `><` 表情单独作为允许变化的区域。

v0.5.0 将手掌、袖口与纸巾的关键区域作为完整局部移动，肩膀及头发边缘平滑过渡，保留拖动时的腿部惯性；222 个动作采样检查上身网格没有翻折，手部保护区域几何边长误差低于 0.001%。仍是在原始二维图上做局部动画，不能产生原图中不存在的背面和遮挡细节。

`motion.js` 计算动作与弹簧物理；`original-mesh.js` 在原图上做局部变形，并保护脸部；`rig.js` 负责原图渲染、独立的墙、ZZZ 和彩带；`pet.js` 处理鼠标、音频和设置。隐藏页面、收进口袋、关闭陪伴、减少动态效果都会暂停帧循环；拖动只在松手后写入位置。

本地 file:// 预览受浏览器 WebGL 同源限制，因此 `original-art-data.js` 仅封装同一张 PNG 的原始字节，源文件 SHA256 也纳入检查。`node scripts/prepare-original.cjs` 可重建该封装。普通网页和扩展页面直接读取 PNG。
